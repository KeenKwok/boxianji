# 《拨弦记》编辑操作手册（Editorial Handbook）

> 一次采集，多次使用。

本手册用于统一《拨弦记》的编辑规范、数据规范、发布流程及版本规划。

适用于：

- GitHub Pages 网站
- 演出情报（attention）
- 弹拨乐一周简报（weekly）
- 微信公众号
- 小红书
- 微信视频号
- RSS
- JSON
- 后续 AI Agent / Codex 自动化流程

---

# 一、项目定位

《拨弦记》（Boxianji）是一个面向中文用户的弹拨乐开放资讯项目。

核心价值不是转载资讯，而是：

> 帮用户减少寻找信息的动作。

所有开发和运营决策遵循：

> 数据负责生长，页面负责呈现。

---

# 二、核心原则

## 一次采集，多次使用

一条演出信息一旦入库，应同时服务于：

- 网站
- 首页
- RSS
- JSON
- 周报
- 后续小程序

禁止重复维护同一份数据。

## 人工审核优先

AI负责：

- 发现
- 整理
- 结构化

人工负责：

- 判断
- 取舍
- 发布

编辑判断始终保留。

## 唯一数据源

所有演出数据以：

`_data/attention.yml`

为唯一数据源。

网站、RSS、JSON、首页及未来周报引用均不得维护独立副本。

---

# 三、演出数据规范

统一 Schema：

```yaml
id:
date:
city:
title:
performers:
instruments:
link:
```

## 字段说明

| 字段 | 规则 |
|------|------|
| id | 自动生成 |
| date | YYYY-MM-DD |
| city | 中文城市名 |
| title | 官方标题 |
| performers | 中文名数组 |
| instruments | 宽分类数组 |
| link | 公众号链接 |

## 演奏者规范

统一使用中文标准名。

例如：

```yaml
performers:
  - "约兰·索舍尔"
```

英文原名保留在标题需要时出现，不单独存入字段。

## 多位演奏者

使用数组。

```yaml
performers:
  - "王健"
  - "约兰·索舍尔"
```

## 乐器规范

采用宽分类。

| 使用 | 不使用 |
|------|--------|
| 吉他 | 古典吉他 |
| 古筝 | —— |
| 琵琶 | —— |
| 中阮 | —— |

目的：

便于未来筛选、统计及自动化处理。

## 空字段

允许为空。

```yaml
performers: []
instruments: []
```

页面自动隐藏，不删除字段。

# 四、演出入库流程

标准流程：

发现演出

↓

AI解析

↓

YAML生成

↓

人工审核

↓

公众号贴图发布

↓

补公众号链接

↓

attention.yml

## AI 固定输出格式

每次执行“入库”，固定返回：

1. 自动识别结果
2. YAML（可直接复制）
3. 待确认项
4. 入库检查

示例：

```yaml
- id: "20260927-guangzhou-goran-sollscher"
  date: "2026-09-27"
  city: "广州"
  title: "约兰·索舍尔独奏音乐会"
  performers:
    - "约兰·索舍尔"
  instruments:
    - "吉他"
  link: ""
```

公众号发布后，仅补：

```yaml
link: "https://mp.weixin.qq.com/..."
```

# 五、周报制作流程

发布时间：

每周六。

制作流程：

Grok

↓

豆包

↓

ChatGPT核验

↓

生成Markdown

↓

发布

## 周报固定结构

1. 编辑导语
2. 近期重要演出（未来14天）
3. 艺术节、赛事与学术动态
4. 乐器制作、非遗与文化动态
5. 音乐会、展会展演与乐团动态
6. 人物资讯
7. 拨弦听曲

## 演出栏目规则

唯一数据源：

`attention.yml`

规则：

- 自动生成未来14天候选演出；
- 按日期排序；
- 编辑精选约3–6场；
- 不复制整个数据库。

原则：

周报是编辑产品，不是数据库。

# 六、平台运营规范

| 平台 | 职责 |
|------|------|
| 网站 | 长期数据库 |
| 公众号 | 详细资讯 |
| 小红书 | 公域传播 |
| 视频号 | 巡演传播 |
| RSS | 持续订阅 |
| JSON | 开放数据 |

## 微信公众号

- 常规内容：11:30–12:30 优先。
- 周报：周六中午固定。
- 重大资讯：及时发布。

## 小红书

重点：

- 钩子标题；
- 公域传播；
- 避免明显站外引流。

## 视频号

仅发布：

- 中国巡演；
- 多城巡演；
- 国际大师；
- 大型民族乐团巡演。

不做所有演出同步。

# 七、命名规范

## 文件命名

```text
weekly/YYYY-MM-DD.md
```

演出数据：

`attention.yml`

图片：

```text

```

保持统一。

## 日期格式

统一：

```
YYYY-MM-DD
```

禁止使用：

- YY.MM.DD
- MM.DD

人工审核

↓

公众号发布

↓

# 十、项目信条

《拨弦记》的长期建设遵循以下原则：

- 数据负责生长，页面负责呈现。
- 一次采集，多次使用。
- AI负责重复劳动，人负责编辑判断。
- 先跑通，再自动化；先验证，再开发。
- 保持极简，不为功能而增加复杂度。

本手册随项目版本持续更新。
